三个关键判断

参数表看不出来的，都在这里

01 / 全钢

「全钢」只有一台真的满足

格米莱 9015C 是官方明确写「全不锈钢机身」的唯一一台。Eureka、Mazzer、DF64、泰摩、海氏都是压铸铝或铝合金机身——铝不代表差，散热和重量反而更好，但如果你要的是「钢」，答案就只有它。

若「全钢」指刀盘：8 台全合格，最硬的是 Mazzer 233M 轴承钢与 DF64 的钛涂层。

02 / 吃粉

贵的机器，残粉可能更差

Mazzer Mini 官方说明书直接写 8g 残粉——它靠预定量、耐用性卖钱，不是靠低残粉。家用每天 1–2 杯的话，8g 意味着你每天有半杯的粉永远出不来。

反过来，DF64 与 Eureka Zero 把「单剂量 + 气吹 + 通道可拆」做成了标配，才是家用的正确形态。

03 / 稳定

稳定 = 刀盘平行度 + 转速恒定

「性能稳定」在磨豆机上是三件事：刀盘平行度（决定粒径一致性）、转速恒定（不因硬豆掉速）、残粉不串味。前两项看电机与出厂校准，第三项看结构。

DF64 玩家普遍反馈「用一周后需要重新做一次刀盘平行度」，这是它的已知特性。

到手先做这个测试（30 秒）

别信「几乎 0 残粉」，自己称一次就知道

1
称 15g 豆，全磨出来接进杯子，再称重——差值就是这台机的起始吃粉量。
2
连续再磨一次 15g。第一次会有一部分粉「填缝」，第二次的差值才是真实残留。这是最容易误判的地方。
3
凑近出粉口闻：先磨一口旧豆再磨新豆，有杂味说明通道里有陈粉，换豆会串味。
4
拆一次：看进豆口是否积粗粉、通道能否取下、刀盘能否快拆。拆得开、看得见、擦得掉，才是真的低残粉。

避坑提醒

⚠ 老款 ≠ 新款的残粉表现。格米莱 9015 老款曾有「18g 豆只出 14.5g 粉、客服回复正常」的公开投诉（3.5g 吃粉）。 9015C 是后续加了单剂量气吹仓和直落式出粉通道的新款，结构确实改了，但不要因为「新款」就跳过上面那个称重测试。

⚠ 「0 残粉」是带引号的营销话术。行业里没有公开的残粉标准，评测里的 0 大多是「肉眼看不到」。 真正的判断标准只有三个：通道能不能拆、刀盘能不能快拆、有没有气吹/振粉/防静电。

⚠ 价格说明。格米莱、海氏为国内电商价（含券后实付）；Eureka、DF64、泰摩、Mazzer 为公开渠道价或海外定价折算， 国内行货、代购、水货差异较大，下单前务必核实是否有中文售后与保修。

先弄懂两个词：淬硬钢 vs 不锈钢

它们不是一个维度的分类，可以同时成立

成分维度

不锈钢

铬含量 ≥10.5%，表面能形成钝化膜，所以不生锈。这是按成分分类。

工艺维度

淬硬钢

淬火 + 回火，组织转变为马氏体，所以硬度高。这是按状态分类——可以是不锈钢，也可以是高碳钢。

关键

440C 淬火后 = 淬硬不锈钢

两者可以同时满足。厂商只写其中一个词时，你其实拿不到完整信息——这也是本站把 3 台机器归入「未标牌号」的原因。

冶金原理

为什么「又硬又不锈」很难

硬度靠碳：碳越高，淬火后越硬、越耐磨。
防锈靠铬：铬 ≥10.5% 才形成钝化膜。
但碳会把铬「锁」进碳化物里，铬被锁住就无法在表面成膜——碳越多，防锈越差。

所以 440C（C≈1.0%、Cr≈17%）是「又硬又不太锈」的极限折中；想再硬，只能加涂层。

更该警惕

淬硬层：表面淬火 vs 整体淬火

表面淬火（高频/渗碳）：外层硬、芯部软，像「M&M 巧克力」。硬化层磨穿后，磨损速度突然加快。

整体淬火（through-hardened）：从里到外都硬，寿命可预测，但更脆、更贵。

磨豆机大量用表面淬火刀盘，所以会出现「前三年好好的，第四年突然调不准」。

不会问？记住这三句：
1.「刀盘是马氏体不锈钢（420/440C）还是高碳钢/轴承钢？」——只说「硬化钢」的，通常没告诉你防不防锈
2.「整体淬火还是表面淬火？淬硬层多深？」——答不出「整体淬火」，默认按表面淬火理解
3.「标称硬度多少 HRC？」——写不出 HRC 的，基本可以认为没做过硬度控制

辨色提示：灰色 = 普通淬火钢　·　亮银 = 加强版（高频淬火）　·　金色 = TiN 涂层　·　黑色 = DLC 涂层。 磁铁没用——不锈钢和高碳钢都有磁性。
